# Demo video script (under 3:00)

Voiceover is about 390 words, roughly 2:40 at a calm pace. **[Brackets]** are what's on screen.

---

**0:00 to 0:15 · The problem**
[The Tidepool Goods cart page with only the "Pay with card" button.]
> This store only takes Stripe. Adding PayPal properly means a new SDK, a database migration, signed webhooks, refunds, and then proving none of it broke Stripe. That's days of careful work.

**0:15 to 0:35 · Install**
[GitHub: install PayPal Checkout Integrator on tidepool-store. The dashboard shows the repository.]
> PayPal Checkout Integrator is a GitHub App by Chui Labs. I install it on the store's repo and click "Add PayPal checkout."

**0:35 to 0:55 · The plan**
[Live run page: the repo map, "9 Stripe files, none will be modified", the 20-file plan. Click "Approve and build".]
> A Claude agent reads the repository and writes a plan first: what it found, every file it will touch, and the Stripe files it won't. Nothing is written until I approve.

**0:55 to 1:25 · The work (time-lapse; caption: "35 minutes, sped up 40×")**
[Live log: APIMatic lookups, the guards turning green, "store: build", scenarios passing.]
> It writes the integration with PayPal's server SDK, generated by APIMatic, and checks every SDK name against APIMatic's Context Plugin and the installed types. Then deterministic gates: build, lint, and four guards, including "Stripe files untouched". The AI doesn't decide if it worked.

**1:25 to 1:45 · The proof**
[The run report video: the sandbox buyer logs in to PayPal and pays.]
> A harness does. It buys from the store with a real PayPal sandbox account. It cancels, gets declined, tampers with the price, replays and forges webhooks, and issues refunds: nine scenarios.

**1:45 to 2:20 · The pull request and report**
[The PR: green "PayPal checkout" check, scenario table. Click "Open the run report": "9 of 9", PayPal API confirmation, Stripe and PayPal rows side by side.]
> The result is a pull request with a green check. The run report shows PayPal's own API confirming each capture, and the PayPal order's database rows matching the same cart bought through Stripe.

**2:20 to 2:45 · It keeps watching**
[A teammate's PR, "Simplify checkout: send the total from the browser". The check turns red; the review comment shows the likely cause.]
> After merge, every pull request gets the check. Here a teammate "simplifies" checkout, and the real sandbox purchase catches it: the price could be tampered with. The comment explains the likely cause, but PayPal's API made the call.

**2:45 to 3:00 · Close**
[Text card: Claude · APIMatic · PayPal JS SDK v6 · Orders v2 · Playwright · Render. "Sandbox only." The Chui Labs logo.]
> PayPal Checkout Integrator, by Chui Labs. Add PayPal and prove it, on every pull request.
